B + C Mix — Claw'd Dance

점프 (B) 와 좌우 tilt (C) 를 다양한 방식으로 섞은 시안 3종. 아래 참조용 원본 B, C 와 같이 비교해보세요.

1.0×

B + C 조합 시안

BC-1. 가벼운 점프 + tilt 0.85s

매 비트마다 살짝 점프하며 양옆으로 기울임. B 와 C 를 동시에 부드럽게 합친 시안.

@keyframes dance-BC1 {
  0%, 100% { transform: translate(0,0) rotate(0deg); }
  25%      { transform: translate(-1.5px,-4px) rotate(-3deg) scaleY(.94); }
  50%      { transform: translate(0,0) rotate(0deg); }
  75%      { transform: translate(1.5px,-4px) rotate(3deg) scaleY(.94); }
}
BC-2. 강한 점프 + tilt 0.75s

큰 점프 + 큰 기울임. 가운데로 떨어질 때 살짝 눌리는 squish 도 추가. 역동적인 톤.

@keyframes dance-BC2 {
  0%, 100% { transform: translate(0,0) rotate(0deg); }
  25%      { transform: translate(-2px,-6px) rotate(-5deg) scaleY(.9); }
  50%      { transform: translate(0,1px) scaleY(1.04); }
  75%      { transform: translate(2px,-6px) rotate(5deg) scaleY(.9); }
}
BC-3. 점프 ↔ 스텝 교대 1.4s

"점프 → 좌-스텝 → 점프 → 우-스텝" 4박자 패턴. 두 동작이 시간에 따라 교대.

@keyframes dance-BC3 {
  0%, 100% { transform: translate(0,0) rotate(0deg); }
  20%      { translateY(-5px) scaleY(.92); }  /* 점프 */
  45%      { translateX(-2px) rotate(-3deg); }    /* 좌-스텝 */
  70%      { translateY(-5px) scaleY(.92); }  /* 점프 */
  92%      { translateX(2px) rotate(3deg); }     /* 우-스텝 */
}
