Claw'd Dance Mode 미리보기

음악이 재생되는 동안 보여줄 댄스 모션 시안 4가지. 마음에 드는 걸 골라주시면 위젯에 적용합니다.
속도 슬라이더로 BPM, mood 버튼으로 색상 변화를 확인할 수 있어요.

1.0×
A. 좌우 흔들기 SQUASH · 0.9s

몸이 좌우로 흔들리며 살짝 눌렸다 펴짐. 가장 익숙한 댄스 톤.

@keyframes dance-A {
  0%, 100% { transform: translateX(0) scaleY(1); }
  25%      { transform: translateX(-2px) scaleY(.96); }
  50%      { transform: translateX(0) scaleY(1); }
  75%      { transform: translateX(2px) scaleY(.96); }
}
B. 비트 점프 BOUNCE · 0.6s

위로 통 튀는 점프. 빠른 BPM 의 신나는 곡과 잘 맞음.

@keyframes dance-B {
  0%, 100% { transform: translateY(0) scaleY(1); }
  40%      { transform: translateY(-5px) scaleY(.92); }
  50%      { transform: translateY(-5px) scaleY(.92); }
}
C. 빠른 두-스텝 TILT · 0.7s

좌우 이동 + 살짝 기울임. 댄스 같은 느낌이 가장 살아남.

@keyframes dance-C {
  0%, 100% { transform: translateX(0) rotate(0deg); }
  25%      { transform: translateX(-1.5px) rotate(-3deg); }
  50%      { transform: translateX(0) rotate(0deg); }
  75%      { transform: translateX(1.5px) rotate(3deg); }
}
D. swag 글라이드 SLOW · 1.4s

큰 폭으로 천천히 옆으로 미끄러짐. lo-fi / chill 톤에 어울림.

@keyframes dance-D {
  0%, 100% { transform: translateX(0) rotate(0); }
  50%      { transform: translateX(3px) rotate(-2deg); }
}

실제 위젯에서는 음악 윈도우의 재생 상태가 메인 위젯으로 전달되어 자동 활성화됩니다.
마음에 드시는 variant 알려주시면 (예: "C가 좋다", "A 인데 좀 빠르게") 위젯에 통합합니다.
